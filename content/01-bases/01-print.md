# Ton premier programme

Dans Scratch, tu utilises le bloc `say Hello!` pour qu'un sprite parle.
En Python, on utilise **`print`** pour afficher du texte dans la console.

Regarde le code à droite et clique sur **▶ Exécuter** (ou `Ctrl+Entrée`).

## Le texte entre guillemets

Un texte s'écrit entre guillemets `"..."`. On appelle ça une **chaîne de caractères** (*string*).

```python
print("Hello World!")
```

## Plusieurs lignes

Python lit le programme **de haut en bas**, une ligne après l'autre, comme les blocs Scratch empilés sous `when green flag clicked`.

## Les nombres et les calculs

Un nombre s'écrit sans guillemets. Python sait calculer :

```python
print(2 + 3)
print(10 * 4)
```
